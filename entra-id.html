01 · ENGINEERING CHALLENGE

Modernizing authentication across an enterprise application landscape

A leading U.S. insurance carrier was transitioning more than 70 enterprise applications from SiteMinder-based authentication to Microsoft Entra ID.

This was not simply an identity-platform configuration exercise. Applications had to be integrated with the new authentication model, identity components configured in Entra ID, security controls applied and production applications migrated without interrupting business access. I led the migration directly alongside my team lead, as part of a lean core team of 2–3 engineers. For some applications, the owning application teams carried out their own migration, working under guidance and standards I defined.

Scale

70+ enterprise applications requiring coordinated authentication modernization.

Engineering

Continuity

Production migration had to preserve access to business-critical applications.

04 · APPLICATION & SSO INTEGRATION

Integrating applications with the new authentication model

Applications across the portfolio had different authentication requirements. Integration therefore needed to accommodate SAML, OAuth 2.0 and OpenID Connect while presenting a consistent enterprise Single Sign-On experience.

The work included configuring the application identity in Entra ID and making the corresponding application-side integration changes required for the selected authentication flow. For each Java or .NET application, the existing authentication flow was first understood and the appropriate target integration pattern identified before the Entra ID configuration was created and the application updated to use the new identity provider.

On applications where the owning application team carried out the integration themselves, I provided the integration pattern, reviewed the Entra ID configuration and validated the resulting authentication flow before production cutover.

05 · REUSABLE SSO ENGINEERING

07 · MIGRATION ENGINEERING

Moving production applications without disrupting access

Authentication is a critical application dependency. A migration failure can leave an otherwise healthy application inaccessible. The modernization therefore had to move applications incrementally while maintaining business continuity.

A zero-downtime migration strategy was executed across the application portfolio by a lean, hands-on team.

Each application was assessed individually to understand its existing authentication flow, access requirements and target integration pattern. The corresponding Entra ID configuration and application integration were then prepared and validated before production migration. Authentication scenarios were tested before cutover to verify that expected users could sign in and reach the application with the correct access. The application-by-application approach allowed the migration to progress incrementally rather than treating the entire portfolio as a single high-risk production cutover.
