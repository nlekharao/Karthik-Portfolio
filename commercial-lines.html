01 · APPLICATION CONTEXT

Engineering within a commercial insurance platform

Enterprise policy systems bring together business workflows, application logic, data and external integrations.

The platform supports policy administration within the commercial insurance domain. Development work spans the application interface, server-side functionality, data handling and integrations with external systems.

The application uses Sencha Ext JS on the user-interface layer, ASP.NET for application functionality and MongoDB for data persistence.

The work therefore involves engineering across multiple layers of an existing enterprise application rather than developing an isolated standalone feature.

03 · FEATURE FOCUS · VYMO INTEGRATION

Connecting policy data with a sales engagement platform

How can information already held within the policy administration system support downstream sales activity?

A current area of development is the integration of the commercial lines application with Vymo, an external sales engagement platform.

The integration connects information from the policy administration environment with Vymo so that relevant customer or policy context can support lead and opportunity workflows.

From an engineering perspective, this introduces a system boundary: information has to move between two applications through a defined API integration while remaining usable within the commercial-lines workflow.

04 · ENGINEERING THE INTEGRATION

Turning an external API into application functionality

API integration involves more than simply making an HTTP request.

The Vymo feature requires the policy administration application to communicate with an external platform through an API and translate that interaction into functionality usable within the existing application.

This means aligning the application's internal data with the external API contract, handling the returned information and making the integration part of the appropriate business workflow.

The precise authentication, mapping, validation and failure-handling mechanisms are being kept out of the public description until the implementation details are confirmed.

Integration Engineering
Application Data Identify the internal customer or policy information required by the external integration.
API Contract Map application data to the structure expected by the external API.
Response Handling Process information returned by the external platform for use within the application.
Application Workflow Surface the integrated information within the appropriate commercial-lines workflow.
