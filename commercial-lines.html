03 · FEATURE FOCUS · VYMO INTEGRATION

Bringing sales opportunities into the agent workflow

One of the major features currently under development is an integration with Vymo. The objective is to use existing customer and policy information to help surface potential sales opportunities that can be presented to agents within their working environment.

Current Development

Connecting policy data with sales intelligence

The feature requires the policy administration platform and Vymo to exchange information so that relevant customer or policy data can contribute to opportunity identification and the resulting information can be made useful to insurance agents.

04 · ENGINEERING THE VYMO INTEGRATION

Designing the application-to-platform integration

The Vymo feature introduces an external-system integration into the policy administration workflow. The implementation therefore involves more than simply calling an API: the application needs to prepare the appropriate business data, exchange it with the external platform and handle the resulting information within the existing application.

Data Mapping

Mapping information from the policy administration domain into the data structures required by the Vymo integration.

API Integration

Implementing the application-side integration required to exchange information with Vymo.

Response Handling

Handling information returned through the integration so that it can be consumed by the commercial-lines application.

Agent Experience

Integrating the resulting business information into the application's existing workflow for agents.
