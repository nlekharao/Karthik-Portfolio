01 · Machine Learning & Model Robustness

Adversarial Machine Learning

How robust are neural networks when inputs are deliberately manipulated?

Investigated vulnerabilities in neural-network classification models by applying adversarial attack techniques and evaluating how model performance changed when carefully constructed perturbations were introduced into the input data.

The project explored Fast Gradient Sign Method (FGSM) and DeepFool attacks and produced benchmarks to compare model robustness under different attack strategies.

02 · AR / VR & Real-time Data

AR/VR Wearables Module

Turning wearable-device data into an immersive, real-time experience.

Developed an AR/VR interaction module with Intel for real-time visualization of data from wearable devices using Unity and C#.

The project explored how data generated by wearable devices could be represented and interacted with within an immersive environment rather than through a conventional application interface.

03 · Data Analytics & Forecasting

Big Data Analytics for Photovoltaic Systems

Using weather and system data to forecast solar-power generation.

Built a data-analytics approach for real-time photovoltaic-system monitoring and weather-based power-generation forecasting, with the objective of supporting proactive maintenance scheduling.

The project combined photovoltaic-system information with weather data to estimate future power generation and identify potential operational insights.
