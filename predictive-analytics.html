PROJECT 02 · MACHINE LEARNING & PREDICTIVE ANALYTICS

Predicting Conversion Through Machine Learning

Building regression-based machine learning models for a U.S. property & casualty insurance carrier to predict user conversion likelihood, identify key drop-off factors and support more targeted, data-driven engagement decisions.

Industry Property & Casualty Insurance
Problem Conversion Prediction
Focus Predictive Modeling · Feature Engineering
Machine Learning Regression Predictive Modeling Feature Engineering Python scikit-learn Pandas NumPy
01 · PROBLEM & OBJECTIVE

Understanding which users are likely to convert

Can behavioural data help identify conversion likelihood before a user drops out of the journey?

The project focused on using historical user data to build predictive models that could estimate the likelihood of a user converting.

The objective was not only to generate a prediction, but also to understand which factors were most strongly associated with conversion and where users were more likely to drop off.

These insights could then support more targeted, data-driven engagement decisions.

Analytical Objective
Predict Estimate the likelihood that a user will convert.
Explain Identify the factors most associated with conversion and drop-off.
Inform Support more targeted engagement decisions using model-derived insights.

Model quality depends heavily on how the underlying data is prepared and represented.

Feature importance analysis was subsequently used to understand which variables contributed most strongly to the model's predictions.
