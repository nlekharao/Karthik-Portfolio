PROJECT 02 · DATA ANALYTICS & MACHINE LEARNING

User Conversion & Drop-off Analysis

Analysed approximately 20,000 user interactions for a U.S. property & casualty insurance carrier to understand navigation patterns and identify where users dropped off before converting. Built Logistic Regression and Random Forest models to predict conversion likelihood, then translated the findings into UX recommendations and a web prototype.

01 · THE PROBLEM

Understanding conversion and drop-off

Where were users leaving the application journey before converting — and what patterns could help explain why?

The project focused on understanding how users navigated through an insurance application and identifying where they were most likely to drop off before conversion.

Approximately 20,000 historical user interactions provided visibility into activity across the application journey, making it possible to examine navigation patterns and the points at which users stopped progressing.

The objective was to combine behavioural analysis with machine learning to understand conversion likelihood, identify important drivers of drop-off and give the application team a stronger basis for improving the user experience.

03 · MACHINE LEARNING

Modelling conversion likelihood

Logistic Regression and Random Forest were used to examine conversion likelihood and the drivers associated with drop-off.

Logistic Regression and Random Forest models were built using the historical interaction data to predict the likelihood of user conversion.

The data was divided using a 60:40 training and test split. Model performance was evaluated on the held-out test data, with ROC analysis used as part of the evaluation.

Feature importance was also used to identify the key drivers associated with user drop-off, helping connect the modelling results back to the behaviour observed across the application journey.

The models were used as part of an analytical study rather than deployed as a live prediction service. Their purpose was to generate insights that could inform application and UX improvements.

04 · FROM INSIGHT TO PROTOTYPE

Translating analysis into application improvements

The analysis was taken beyond model results to explore how conversion and the user experience could be improved.

Findings from the journey analysis and machine-learning models were translated into recommendations for improving conversion and the overall user experience.

Based on these findings, I developed a web prototype reflecting the suggested changes. This provided a practical way to demonstrate how insights from the analysis could translate into changes within the application experience.

The prototype complemented the analytical work by connecting the data and modelling results to a tangible application outcome.

05 · OUTCOME

Turning behavioural data into actionable recommendations

The final output connected user behaviour, machine learning and application development around a practical business problem.

The analysis identified patterns in user conversion and drop-off and used machine learning to examine conversion likelihood and the key drivers associated with users leaving the journey.

Findings were translated into recommendations for improving conversion and UX, supported by a web prototype demonstrating the suggested changes.

The results were presented to application stakeholders, giving the team a data-driven basis for considering further improvements to the application experience.
